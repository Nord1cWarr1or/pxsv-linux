# pxsv-linux

Порт **PrimeXT Sprite Viewer** (`pxsv`) под Linux: просмотрщик спрайтов (`.spr`) для GoldSrc / Xash3D / Counter-Strike 1.6.
Окна нативные, на **Qt 6**, отрисовка через OpenGL. Хорошо работает и под **Wayland**, и под X11.

Это самостоятельный репозиторий только для этого просмотрщика: из PrimeXT взято лишь то, что нужно для сборки `pxsv`.
Движка, игры, остальных утилит, vcpkg, PhysX и submodules здесь нет.

## Возможности

- Открытие спрайтов GoldSrc (`.spr`): обычные кадры и группы кадров, анимация, список недавних файлов.
- Режимы отрисовки: Normal, Additive, Indexalpha, Alpha test.
- Ориентации: Parallel Upright, Facing Upright, Parallel, Oriented, Parallel Oriented.
- Покадровый просмотр (кнопки `<<` / `>>`), регулировка скорости анимации, автоплей.
- Фоновая и «земляная» текстуры (`.bmp`, `.tga`, `.pcx`), настройка цветов фона, земли и света.
- Скриншот области просмотра (Options → Make Screenshot).
- Просмотр PAK-архивов и загрузка из них спрайтов и текстур.

## Управление

| Действие | Что делает |
|---|---|
| ЛКМ + движение | вращение |
| ПКМ + движение | приближение / отдаление |
| Shift + ЛКМ + движение | сдвиг по осям X и Y |
| Options → Center View / Reset View | вернуть камеру |

## Сборка

Зависимости: компилятор C++17, CMake ≥ 3.19, Qt 6 (Widgets, OpenGL, OpenGLWidgets) и OpenGL (Mesa или проприетарный драйвер).

Arch / CachyOS:

```sh
sudo pacman -S --needed base-devel cmake ninja qt6-base mesa
```

Debian / Ubuntu:

```sh
sudo apt install build-essential cmake ninja-build qt6-base-dev libgl1-mesa-dev
```

Сборка и запуск:

```sh
git clone <этот репозиторий> pxsv-linux && cd pxsv-linux
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/pxsv                      # пустое окно, спрайт открыть через File → Load Sprite
./build/pxsv path/to/sprite.spr   # сразу открыть спрайт
```

Установка в системный префикс (по желанию): `cmake --install build --prefix ~/.local`.

## Wayland и X11

По умолчанию используется платформа сессии (в Wayland это нативный Wayland). Принудительно переключить платформу можно переменной окружения:

```sh
QT_QPA_PLATFORM=xcb ./build/pxsv       # через XWayland / X11
QT_QPA_PLATFORM=wayland ./build/pxsv   # нативный Wayland
```

Просмотрщик использует «старый» OpenGL (`glBegin`, матричный стек), поэтому при запуске запрашивается
десктопный OpenGL с compatibility-профилем. Без этого Qt 6 на Wayland создаёт OpenGL ES, в котором
этих функций нет, и спрайт не рисуется.

## Чем отличается от оригинала

Оригинальный `pxsv` из PrimeXT собирается под Linux, но работает на нём плохо (особенно под Wayland).
Здесь исправлено:

- **Переход с Qt 5 на Qt 6.** Qt 5 на Wayland (особенно с NVIDIA и дробным масштабом) оставлял «смаз» в диалогах.
- **Принудительный desktop OpenGL** в compatibility-профиле (см. выше).
- **Контекст OpenGL перед загрузкой.** В версии для Windows контекст был глобальным, а `QOpenGLWidget` создаёт его лениво. Теперь контекст делается текущим перед загрузкой спрайтов и текстур, а при старте программа ждёт его создания.
- **Имена текстур через `glGenTextures`.** Раньше использовались зашитые номера 1, 2, 3…, которые пересекались с объектами Qt.
- **Сброс текстурного состояния** в начале кадра: после композитинга `QOpenGLWidget` фиксированный конвейер «залипал», и спрайт со второго кадра рисовался чёрным.
- **Прозрачность очистки.** Фон очищался с альфой 0, и на Wayland область просмотра была белой.
- **HiDPI.** Размер `glViewport` теперь считается в физических пикселях (`devicePixelRatio`).
- **Часы анимации.** `mx::getTickCount()` использовал `clock()`, то есть процессорное время, и анимация почти стояла. Теперь монотонные часы.
- **События мыши.** Событие отпускания кнопки не передавалось, и после клика в области просмотра анимация зависала навсегда. Модификаторы Ctrl/Shift читались из состояния кнопок, из-за чего не работал сдвиг по Shift+ЛКМ.
- **Выпадающие меню** привязаны к родителю. Без этого под Wayland они открывались отдельными окнами.
- **Сборка.** Самостоятельный CMake-проект без vcpkg и submodules, только Qt 6 и OpenGL.

База: [SNMetamorph/PrimeXT](https://github.com/SNMetamorph/PrimeXT), коммит `64fe05d`.

## Известные ограничения

- Окно **Tools → File Associations** (какой программой открывать файлы из PAK) на Linux практически бесполезно: запуск внешних программ реализован только для Windows.
- Просмотрщик PAK-архивов унаследован от оригинала и проверялся мало.
- Исходная архитектура интерфейса (`mxtk`) создана в 1999 году, поэтому часть элементов выглядит нестандартно.

## Структура репозитория

```
src/pxsv/          код просмотрщика
src/game_shared/   математика и строки (из PrimeXT)
src/utils_common/  командная строка, файловая система, память (из PrimeXT)
src/common/        заголовки движка (из PrimeXT)
src/engine/        заголовки движка (из PrimeXT)
src/public/        определение платформы и сборки (из PrimeXT)
third_party/mxtk/  библиотека интерфейса mxtk, только бэкенд Qt
cmake/             генерация build_info_gen.h (хеш коммита в окне About)
```
